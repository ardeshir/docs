## DOL v0.4.0 "HIR Complete"

**Release Date:** December 28, 2025
**Tag:** v0.4.0
**Milestone:** Phase 2a Complete - High-level Intermediate Representation

---

### Highlights

This release marks the completion of the HIR (High-level Intermediate Representation) layer, which was announced as enabling the full DOL -> HIR -> MLIR -> WASM compilation pipeline.

> **Correction (2026-11-21), checked at DOL v0.8.2:** the MLIR stage is not a working pipeline stage. `src/mlir` is about 2.9k lines with 48 stub markers, feature-gated, does not build without MLIR headers, and is not in CI. The working WASM backend (`src/wasm`, beta) compiles directly from the AST; HIR is kept for diagnostics only on that path. The diagram below is the pipeline as announced at release.

```
┌─────────────────────────────────────────────────────────────────────────────┐
│                                                                             │
│    .dol source → HIR → MLIR → WASM → .spirit                               │
│         ✅        ✅     ✅      ✅       ✅                                 │
│                                                                             │
│    Proof: wasmtime run --invoke add add.wasm 5 7                           │
│    Output: 12                                                               │
│                                                                             │
└─────────────────────────────────────────────────────────────────────────────┘
```

### New Features

- **HIR Architecture**: 22 canonical node types for cleaner codegen
  - `HirModule` - Top-level compilation unit
  - `HirDecl` - Declaration nodes (gene, trait, function)
  - `HirExpr` - Expression nodes with type annotations
  - `HirStmt` - Statement nodes with control flow
  - `HirType` - Type representation nodes

- **Type System Enhancements**
  - Bidirectional type inference
  - Generic type parameters
  - Trait bounds and constraints
  - Type unification algorithm
  - *Note (v0.8.2):* type errors are still not enforced by `dol-check`, validation or WASM compilation, and generic parameters on `gen`/`trait` are parsed but dropped.

- **MLIR Backend** (stub code; see the correction above)
  - HIR to MLIR lowering
  - WASM dialect generation
  - Validated output with wasmtime
