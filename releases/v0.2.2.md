# DOL v0.2.2 "Bootstrap"

> **Released:** December 26, 2025
> **Codename:** Bootstrap
> **Milestone (as claimed at release):** Self-Hosting Complete

> **Correction (2026-11-21):** the self-hosting claims in these historical notes do not hold. Checked at DOL v0.8.2: the DOL-in-DOL bootstrap sources (`dol/*.dol`) parse, but the Rust crate generated from them fails with 850 compile errors; `stage1/` contains only a `Cargo.toml` and `stage2/` does not exist. DOL is **not** self-hosting. See [DOL Bootstrapping](../dol/BOOTSTRAP.md).

---

## Overview

DOL v0.2.2 was announced as completing Year 1 "Genesis" with a working
self-hosting compiler that compiles its own source code to valid Rust. That claim does not hold (see the correction above).

This release represents the culmination of a year's work:
- Q1: Turing Extensions (v0.1.x)
- Q2: Meta-Programming (v0.2.0)
- Q3: MLIR/MCP Server (v0.2.1)
- Q4: Self-Hosting Bootstrap (v0.2.2)

---

## Self-Hosting Bootstrap (as reported at release)

At release, the following DOL source files were reported to compile to valid Rust (re-checked at v0.8.2, the 0.2.2 bootstrap output gives 19 errors):

- `ast.dol` - Abstract Syntax Tree definitions
- `token.dol` - Lexer token types
- `bootstrap.dol` - Compiler bootstrap logic

**Reported result:** 2544 lines of generated Rust, 0 compilation errors. *Re-checked at v0.8.2: 19 errors.*

## What's New in v0.2.2

### Self-Hosting Bootstrap (as claimed at release; not reproducible)
- Bootstrap sources (`ast.dol`, `token.dol`, `bootstrap.dol`) generate 2544 lines of Rust
- Reported 0 compilation errors at the time (19 errors when re-checked at v0.8.2)
- A full bootstrap cycle was never demonstrated: `stage1/` holds only a `Cargo.toml` and `stage2/` does not exist

### Codegen Improvements
- Recursive type handling with `Box<T>`
- String pattern matching with `.as_str()`
- Proper derive macro constraints (no `Eq` with f64)
- Tuple variant wrapper structs
- Reserved keyword escaping (`r#type`)
- Macro invocation syntax (`println!()`)

### Test Suite
- 741+ tests passing (up from 590 in v0.2.0)
- Bootstrap verification tests
- Generated code compilation tests

## Cumulative Features (Year 1)

### From v0.1.x (Turing Extensions)
- Control flow: `if/else/match/for/while/loop`
- Pattern matching with guards
- Lambda expressions
- Pipe operators: `|>`, `>>`, `<|`
- Type inference in the type checker (type errors are not enforced by `dol-check`/the WASM compiler as of v0.8.2)

### From v0.2.0 (Meta-Programming)
- Quote/Eval: `'expr`, `!quoted`
- Reflection: `?type`
- Idiom Brackets: `[| |]`
- 18 Built-in Macros
- Macro expansion system

### From v0.2.1 (MLIR/MCP)
- MLIR code generation (stub code; feature-gated, does not build without MLIR headers, not in CI)
- WASM backend
- MCP server integration

### v0.2.2 (Bootstrap)
- Self-hosting bootstrap (claimed; not reproducible)
- Bootstrap verification
