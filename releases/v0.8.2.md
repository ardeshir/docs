# DOL v0.8.2 Release Notes

**Release Date:** November 20, 2026
**Codename:** Spirit Hosting H0 ("toolchain truth")

---

## Overview

DOL v0.8.2 makes DOL-compiled Spirits link and run in the VUDO VM. The univrs/vudo repository (VUDO VM and `vudo` CLI) depends on `dol = "0.8.2"`, and its CI compiles a DOL program to WASM and runs it in the VM. It is currently the only production consumer of the DOL compiler.

The language syntax is unchanged from v0.8.0 "Clarity" (`gen`/`rule`/`evo`/`docs`, lowercase Rust-style types).

---

## VUDO Host ABI

Bodiless `sex fun host_*` declarations import from WASM module `vudo` with the VM linker's exact signatures (`src/wasm/host_abi.rs`). Previously they imported from `loa` and could not link.

```dol
sex fun host_log(level: i64, msg: string) -> i64

sex fun hello() -> i64 {
    return host_log(2, "hello from DOL")
}
```

- The VM provides 15 host functions: `host_time_now`, `host_random_bytes`, `host_log`, `host_storage_read`, `host_storage_write`, `host_storage_delete`, `host_network_connect`, `host_network_listen`, `host_network_broadcast`, `host_credit_balance`, `host_credit_transfer`, `host_credit_reserve`, `host_credit_release`, `host_credit_consume`, `host_credit_available`.
- A `sex fun` the VM does not provide (unknown name, wrong arity, float where the host expects an integer) is a compile error.
- String literals, `string` parameters and typed string locals passed to `host_*` functions lower to `(ptr, len)`. Modules that import pointer-taking host functions export `memory`.
- `compile_source` and the Spirit pipeline emit real WASM instead of a placeholder module.
- `dol-abi`: new `vm_host_functions()` (the 15 VM host functions). `standard_host_functions()` (22 `vudo_*` names) is deprecated.

## Known Limitations

- `dol-parse` and `dol-check` only parse the first declaration in each file. `metadol::parse_file_all` parses whole files.
- Type errors are not enforced by validation, `dol-check --typecheck` or WASM compilation.
- The WASM backend covers a subset of the language. Unsupported: lambdas, tuples, lists, `sex {}` blocks, `?`, quote/meta, idiom brackets, `this`, casts, and `for` over anything other than a range. Gene layouts reject `u64` and `string` fields.
- vudo.univrs.io still runs an in-browser dol 0.8.0 build and cannot run 0.8.2 host-calling Spirits.
- The DOLOS Spirit host (univrs-network) runs `vudo_vm` but does not compile DOL.
- DOL is not self-hosting.

## Installation

```bash
# CLI tools need the `cli` feature
cargo install dol --version 0.8.2 --features cli
```

Installs `dol-parse`, `dol-check`, `dol-test`, `dol-codegen`, `dol-migrate`, `dol-mcp`, `dol-build` and `dol-build-crate`. Minimum supported Rust version is 1.84.

As a library (the library name is `metadol`):

```toml
[dependencies]
dol = { version = "0.8.2", features = ["wasm-compile"] }
```
