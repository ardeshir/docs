# DOL v0.2.0 Release Notes

**Codename:** Meta-Programming
**Date:** December 25, 2025 (tagged; published to crates.io December 27, 2025)

> Code examples below were updated to v0.8 syntax and checked to parse with DOL 0.8.2; forms that no longer parse are marked.
**Tests:** 590 passing

## Highlights

DOL v0.2.0 completes Q2 of the Year 1 roadmap with full meta-programming support. You can now manipulate DOL code as data, reflect on types at runtime, and use macros for compile-time code generation.

## New Features

### Quote and Eval

Capture expressions as AST data and evaluate them dynamically:

```dol
fun quote_demo() -> i64 {
    // Quote captures AST
    val ast = '(1 + 2 * 3)    // Quoted<i64>

    // Eval executes quoted expressions
    val result = !ast         // 7
    return result
}
```

The `!'(x + y) where { x = 10, y = 5 }` form shown in the original notes does not parse in 0.8.2.

### Quasi-Quote and Unquote

Build AST templates with dynamic holes:

```text
x = 5
template = `(1 + ~x)   // Splice x into template
result = !template     // 6

fun make_adder(n: Int64) -> Quoted<Expr> {
    return `(x + ~n)
}
```

### Reflection

Get type information at runtime with the `?` operator:

```dol
gen Person {
    has name: string
    has age: i64
}

docs { A person with a name and an age. }

fun describe(person: Person) {
    val info = ?Person
    for field in info.fields {
        println(field.name + ": " + field.type_name)
    }

    // Check trait implementation
    if ?Person.implements(Serializable) {
        serialize(person)
    }
}
```

### Idiom Brackets

Applicative functor syntax sugar:

```dol
fun idiom_demo() {
    // Instead of writing `add <$> mx <*> my`, write:
    val result = [| add mx my |]

    // Desugaring:
    // [| f |]       ->  f
    // [| f a |]     ->  f <$> a
    // [| f a b |]   ->  (f <$> a) <*> b
}
```

### Macros

18 built-in macros for code generation and compile-time operations:

```dol
fun macro_demo(count: i64, expected: i64, actual: i64, name: string) {
    // Debug printing
    val value = #dbg(compute_something())

    // Assertions
    #assert(count > 0, "count must be positive")
    #assert_eq(expected, actual)

    // String operations
    val msg = #format("Hello, {}!", name)
}
```

The original notes also showed `#derive(Debug, Clone)` and `#cfg(target.wasm)` placed before a declaration; that placement does not parse in 0.8.2.

```bash
cargo test
```
