# DOL v0.6.0 Release Notes

**Release Date:** January 1, 2026
**Codename:** Gene Inheritance

---

## Overview

DOL v0.6.0 focuses on WASM compilation improvements, specifically implementing gene inheritance for WebAssembly targets.

---

## New Features

### Gene Inheritance for WASM Compilation

The WASM compiler now supports gene inheritance hierarchies:

```dol
gen Animal {
    has name: string
    has age: i32
}

docs { An animal with a name and an age. }

gen Dog extends Animal {
    has breed: string
}

docs { A dog is an animal with a breed. }
```

> Example updated to v0.8 syntax. Note (v0.8.2): the WASM backend's gene layouts reject `u64` and `string` fields, so this exact example does not compile to WASM; integer and float fields do.

When compiled to WASM, inheritance relationships are properly preserved with:
- Field composition from parent genes
- Method resolution following inheritance chains
- Type compatibility for polymorphic operations

## Changes

### WASM Backend

- Implemented gene inheritance in WASM compilation (`feature/gene-wasm` PR #3)
- Updated test plan with gene inheritance status
- Fixed edge cases in inherited field handling

```bash
# From crates.io (CLI tools need the `cli` feature)
cargo install dol --version 0.6.0 --features cli

# From source
git clone https://github.com/univrs/dol.git
cd dol
git checkout v0.6.0
cargo build --release
```
