# DOL v0.2.3 "Stage2"

> **Released:** December 27, 2025
> **Codename:** Stage2
> **Milestone (as claimed at release):** Full Self-Hosting Verified

> **Correction (2026-11-21):** the self-hosting claims in these historical notes do not hold. Checked at DOL v0.8.2: the DOL-in-DOL bootstrap sources (`dol/*.dol`) parse, but the Rust crate generated from them fails with 850 compile errors; `stage1/` contains only a `Cargo.toml` and `stage2/` does not exist. DOL is **not** self-hosting. See [DOL Bootstrapping](../dol/BOOTSTRAP.md).

---

## Overview

At release, DOL v0.2.3 "Stage2" was announced as proving that the self-hosting compiler works end-to-end, i.e. that the compiler
compiled from DOL sources (Stage2) can:

- Parse DOL files
- Generate Rust code from DOL
- Bootstrap the entire toolchain

This claim does not reproduce today (see the correction above).

```toml

```
